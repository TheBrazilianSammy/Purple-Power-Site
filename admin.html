Publicação

Este painel funciona como rascunho no navegador. O GitHub Pages é estático, então salvar aqui não publica automaticamente para todos os visitantes.

Ainda não guardaste um rascunho.

Os dados guardados ficam apenas neste navegador/dispositivo. Usa “Exportar dados” para guardar um ficheiro JSON de backup.

Como publicar de verdade

  1. Guarda os dados e exporta o ficheiro JSON.
  2. Para atualizar o site público, é necessário ligar o painel a um serviço online (por exemplo, Supabase) ou atualizar os arquivos no GitHub.
  3. Não coloques tokens privados do GitHub ou senhas secretas dentro de um site público.
